# Экспорт смешанных весов

Исходная модель — multilingual Whisper Small в формате GGML FP16. Сценарий сборки закрепляет ревизии модели и whisper.cpp v1.8.2, проверяет SHA-256 весов и применяет [патч загрузчика](../patches/whisper-mixed.patch). [Исходная модель](https://huggingface.co/ggerganov/whisper.cpp/blob/5359861c739e955e79d9a303bcbc70fb988958b1/ggml-small.bin) · [Сценарий сборки](../scripts/setup_runtime.py)

```sh
uv run scripts/setup_runtime.py --backend cpu
uv run scripts/export_model.py policies/m3_enc1.json .work/models/m3_enc1.bin
```

**Карта битности** задаёт формат по умолчанию и исключения по имени тензора. Например, [m3_enc1](../policies/m3_enc1.json) использует Q4_0 по умолчанию и Q8_0 для четырёх проекций в каждом из 12 блоков. Шаблоны чувствительны к регистру. Каждое правило должно совпасть хотя бы с одним подходящим весом. Два правила на один тензор вызывают ошибку.

**Экспортёр** читает исходный FP16, назначает тип каждой матрице и упаковывает блоки через GGML. Поддержаны Q4_0, Q5_0 и Q8_0. Свёртки, позиционные эмбеддинги и одномерные тензоры сохраняют исходный тип. Перед сохранением экспортёр сверяет фактические типы с картой. [Код и точки подключения метода](../scripts/export_model.py)

**Загрузчик** читает у смешанной модели каталог `WMP1` перед заголовком GGML. В нём указаны имена и типы матриц, для которых действует исключение. Обычные файлы FP16 и равномерно квантованные модели загружаются штатным путём. Равномерные экспорты Q4, Q5 и Q8 побайтно совпали с результатом стандартного `quantize`. [Проверка совместимости](../results/models/stock-quantize.json) · [Хеши моделей](../results/models/checkpoints.csv) · [Типы тензоров](../results/models/tensors.csv)

Обычный экспорт использует округление к ближайшему уровню (RTN). Эксперимент с калибровкой меняет упаковку только у Q/K/V первого блока энкодера. Веса ошибок берутся из активаций на train. Для совместной модели замените метод упаковки при той же карте. [Как повторить калибровку](reproduce.md#калибровка-трёх-матриц) · [Интеграция с командой](team-merge.md)
