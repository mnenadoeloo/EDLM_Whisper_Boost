# EDLM_Whisper_Boost

Как ускорить и сжать Whisper Small в whisper.cpp без потери качества распознавания. Три независимых исследования на общих корпусах: LibriSpeech (EN) и Golos (RU). У каждой папки свой README, свои зависимости и инструкция по воспроизведению. Команды запускаются из папки исследования.

| Папка | Вопрос | Главный результат |
|---|---|---|
| [`mixed-precision/`](mixed-precision/README.md) | Какие матрицы можно хранить в 4 битах, где нужны 8, и сколько даёт короткое аудиоокно | 3,75× к FP16 на CPU Apple M3 Pro: смешанные Q4/Q8 веса вместе с адаптивным окном |
| [`whisper-quantization/`](whisper-quantization/README.md) | Улучшает ли GPTQ качество при том же формате Q4_0 и размере файла | Значимого выигрыша по WER нет. Адаптивное окно ускоряет CPU-прогон в 4,68× (EN) и 7,11× (RU) |
| [`calib/`](calib/README.md) | Помогает ли учёт активаций (imatrix) при квантовании весов | Ошибка слоёв ниже на 33–46%, значимого выигрыша по WER нет. Q5_1 по WER не отличается от FP16 и в 2,6 раза меньше |

Сравнение моделей между исследованиями: [mixed-precision/docs/team-merge.md](mixed-precision/docs/team-merge.md).

Замеры сделаны на разном железе и разных выборках, поэтому скорость и WER из разных папок напрямую сравнивать нельзя.
