# Whisper Small на Apple M3 Pro

Мы проверяли, какие веса Whisper можно хранить в 4 битах, где полезны 8 бит и сколько времени экономит короткое аудиоокно. Для русского использовали команды из Golos, для английского — чтение из LibriSpeech.

- **3,75× к FP16 на CPU** дали смешанные веса и адаптивное окно вместе. На 24 записях каждого языка вклад весов составил 1,48×, сокращение окна на тех же весах дало ещё 2,52×.
- **При одинаковом окне и размере модели** карта под M3 Pro ускорила обработку в 1,061 раза на русском и в 1,047 раза на английском относительно первой смешанной карты. На 128 записях каждого языка WER изменился с 38,70% до 36,89% на RU и остался 4,32% на EN.

## Для команды

[Как добавить модель коллеги и провести общий замер](docs/team-merge.md) · [Запуск на CPU, Metal или CUDA](docs/target-tuning.md) · [Как повторить отдельный эксперимент](docs/reproduce.md)

Для первого запуска нужны Python 3.11+, uv, Git, curl, ffmpeg и компилятор C++. Из корня проекта соберите CPU-версию, подготовьте малую выборку и запустите подбор. Скрипт сам соберёт недостающие Q4 и смешанные веса из закреплённой FP16.

```sh
uv run scripts/setup_runtime.py --backend cpu
uv run --with pyarrow==25.0.1 python scripts/prepare_audio.py
uv run research/tune_target.py --backend cpu --out .work/team-cpu \
  --models fp16 q4_0 m3_enc1 --contexts full 768 --threads 4 \
  --budget-pp 1 --repeats 1 --confirm test
```

В `.work/team-cpu/confirmation-test.json` будут скорость и WER на русском и английском. Список файлов и эталонные тексты лежат в [data/](data/README.md), карты битности — в [policies/](policies/), результаты исследования — в [results/](results/). Веса, WAV и новые прогоны хранятся локально в `.work/`.

## Демо

После первого запуска можно распознать файл, воспроизвести его в реальном времени или говорить в микрофон. Сервер держит одну модель в памяти и показывает текст по мере поступления звука.

```sh
uv run python -m demo.server --resident-model m3_enc1
```
